# StayBlock — Host Free Beta

기존 HTML/CSS/Vanilla JS 기반 호스트 캘린더·공간·예약 관리 프로젝트입니다.

- **Host Free**: 기간 제한 없이 무료. 과거 가입일·plan 값으로 기능을 잠그지 않습니다.
- **Pro**: 선택형 고급 분석·운영 자동화, 추후 제공 예정. 10월 베타에는 결제·업그레이드가 없습니다.
- 예약·결제는 기존 Airbnb/Booking.com 등 OTA에서 진행하며 별도 StayBlock 수수료가 없습니다.
- Orient VIA 게스트 발견·공식 제휴 기능은 후속 범위입니다.

## 실행 및 검사

정적 파일을 로컬 HTTP 서버로 열 수 있습니다. 빌드/외부 패키지는 필요하지 않습니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
node --test tests/*.test.cjs
```

테스트는 원본 inline JS를 Node VM에서 실행하며 합성 데이터·메모리 localStorage·DOM stub을 사용합니다. 실제 브라우저 E2E나 운영 검증을 대신하지 않습니다.

TASK-003A의 별도 로컬 BFF 준비본은 [실행·API·SQL·검증 문서](docs/task-003a-offline-scaffold.md)를 참고하세요. `node bff/dev.cjs`는 루프백에서 미연동 API에 `501 NOT_CONFIGURED`로 응답합니다. 기존 HTML에는 연결하지 않았으며, Supabase/DB 생성·SQL 실행·데이터 이관을 수행하지 않습니다. 새 테스트의 인증/저장소는 합성 메모리 fixture이며 실제 RLS 보안 검증이 아닙니다.

## 파일

- `index.html`: 랜딩·명시적 읽기 전용 데모·기존 로그인
- `app.html`: 호스트 캘린더·예약/공간 관리·CSV/인쇄·수동 iCal·초대
- `pricing.html`: Host Free / 향후 Pro 이용 안내 (결제 없음)
- `invite.html`: 로컬 초대 응답·이메일 앱 열기·개별 초대 ICS

## 데이터와 기능 제한

새 저장소는 빈 예약 목록으로 시작합니다. 기존 localStorage 기록은 자동 삭제·변환하지 않습니다. 이전 버전의 데모 예약과 실제 예약을 확실하게 구분할 수 없으므로 기존 기록은 그대로 보존합니다. 샘플 버튼은 미리보기만 표시하고 저장하지 않습니다. 사용자가 직접 선택하는 초기화·탈퇴는 기존 삭제 동작이므로 주의하세요. 초기화 후 데모를 다시 생성하지 않습니다.

전체 자동 동기화와 숙소 공실 export URL은 미제공입니다. 이전 시뮬레이션 성공/시각/개수는 운영 상태로 표시하지 않습니다. 실제 수동 ICS/URL 가져오기, CSV, 인쇄 및 개별 초대 ICS 코드는 유지됩니다. 파일/샘플 피드는 자동 재동기화되지 않습니다. 초대 응답은 수신자 브라우저에만 저장되고 이메일은 직접 전송해야 합니다.

## 남은 출시 차단 사항

**안전한 실제 다중 호스트 온보딩을 지원한다고 주장하지 않습니다.**

- 평문 비밀번호·로컬 세션, 계정별 데이터 격리·서버 저장/백업 부재
- HTML 출력 주입 위험, CSV escaping/수식 처리
- iCal 채널 단위 삭제/전역 UID 충돌·객실 매핑·시간대/반복/취소 처리; 외부 프록시 URL 전달 위험
- 기존 초기 캘린더 렌더 누락·KST 날짜/월경계·예약 충돌 문제
- 초대 UTF-8/응답 덮어쓰기·종일 ICS·서버 전송/만료 검증 미완성
- 모바일/실 브라우저/실 OTA 호환성 미검증

TASK-002는 정책 및 데모/과금 노출 정리입니다. 위 구조적 문제는 후속 승인 Task에서 처리합니다. main 병합·운영 배포는 GPT 검수와 소유자 승인 전 수행하지 않습니다.
