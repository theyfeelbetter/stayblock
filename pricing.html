자주 묻는 질문
30일 무료 체험 후 자동으로 결제되나요? ▾
아니요. 체험 기간 종료 후 자동 결제되지 않습니다. 계속 사용하려면 직접 구독을 선택해주세요. 체험 종료 후에는 예약 조회만 가능하고 새 예약 추가·수정이 제한됩니다.
체험 기간 중 저장한 예약 데이터는 유지되나요? ▾
네, 체험 종료 후에도 기존 예약 데이터는 그대로 유지됩니다. Premium 구독 후 바로 이어서 사용하실 수 있습니다. (단, 현재 베타 버전은 브라우저 localStorage에 저장됩니다. 같은 브라우저에서 사용해주세요.)
에어비앤비·부킹닷컴 캘린더를 자동으로 가져올 수 있나요? ▾
iCal URL을 입력하거나 .ics 파일을 업로드하면 예약이 자동 등록됩니다. 에어비앤비와 부킹닷컴은 보안 정책상 URL 직접 연동이 제한될 수 있어, .ics 파일 다운로드 후 업로드 방식을 권장합니다. 구글 캘린더는 URL 직접 연동이 가능합니다.
언제든지 해지할 수 있나요? ▾
네, 언제든지 해지 가능합니다. 연간 플랜은 남은 기간에 대한 환불 정책을 별도 안내드립니다. 해지 문의: theyfeelbetter@gmail.com
Team 플랜은 어떤 경우에 필요한가요? ▾
여러 숙소를 운영하거나 직원과 함께 예약을 관리해야 하는 경우, 또는 채널매니저·PMS와 API 연동이 필요한 경우에 적합합니다. 도입 상담은 이메일로 문의해주세요.
