# StayBlock modular productivity UI V2

Static HTML concept for design review only. Entry: `index.html`; linked pages: `calendar.html`, `reservations.html`, `properties.html`. All metrics and reservation IDs are fictional.

- No scripts, auth, cookies, localStorage, form submission, API, iCal or actual guest details.
- No external network dependencies; CSP defaults to deny.
- No deployment on Vercel: `stayblock-preview` remains paused after anonymous access failure.
- Only merge or integrate with production app after UI approval and independent auth/RLS/calendar correctness tests.
